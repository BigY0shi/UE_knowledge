# UE5 Knowledge Base

A curated, searchable database of public GitHub repositories that provide **long-form written documentation, guides, tutorials, and knowledge bases** for **Unreal Engine 5.6 / 5.7** game development.

## 🌐 View the Database

**[→ Interactive GitHub Pages Site](https://bigy0shi.github.io/UE_knowledge/)**

Search, filter, and explore all repositories by topic, difficulty, format, and audience.

## 📊 Data Formats

- **JSON** – `data/ue5-knowledge-base.json` – Full structured data
- **CSV** – `data/ue5-knowledge-base.csv` – Spreadsheet-friendly format
- **Interactive** – `docs/` folder – GitHub Pages searchable site

## ✨ Features

✅ **Searchable** – Full-text search across repo names, topics, tags, and audience  
✅ **Filterable** – By difficulty, format, topic, or UE version  
✅ **Organized** – Curated metadata for each repository  
✅ **Offline-friendly** – Markdown-based, downloadable data  
✅ **AI-ingest-friendly** – Structured JSON for knowledge bases  

## 🎯 Scope

This repository **prioritizes**:
- Long-form markdown documentation
- Written guides and references
- Maintainable knowledge bases
- Practical UE5.6/5.7 workflows

This repository **intentionally excludes**:
- Sample game repositories
- Starter kits and templates
- Code-only examples without substantial written guidance

## 🚀 Setup

To enable GitHub Pages:
1. Go to repository Settings
2. Navigate to Pages
3. Set source to `docs/` folder
4. Save

Site will be available at: `https://bigy0shi.github.io/UE_knowledge/`
