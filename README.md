# UE_knowledge

UE_knowledge is a simple knowledge base for Unreal Engine 5.6/5.7 notes, tips, and references.

## Purpose

- Collect practical Unreal Engine knowledge in one place
- Keep short, searchable notes for common workflows and troubleshooting
- Share reusable guidance for future projects

## Repository Status

This repository currently contains the project README and is ready to grow with additional documentation files.

## Suggested Structure

As content grows, add files by topic, for example:

- `rendering.md`
- `blueprints.md`
- `c++.md`
- `packaging.md`
- `performance.md`

## Contributing

1. Add or update Markdown notes with clear headings.
2. Keep entries concise and practical.
3. Prefer examples that can be copied into real Unreal Engine workflows.
